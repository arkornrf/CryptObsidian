# Гайд: Параллельная работа с Git и GitHub в Android Studio

Этот гайд поможет тебе настроить второй (или десятый) проект отдельно от первого и научит переключаться между ними без путаницы.

---

## 1. Инициализация локального Git
Если твой новый проект еще не "под гитом" (файлы в дереве проекта обычного цвета, а не красные/зеленые):

1. **Включи интеграцию**: В верхнем меню выбери `VCS` -> `Enable Version Control Integration`.
2. **Выбери систему**: В выпадающем списке выбери **Git** и нажми **OK**.
3. **Результат**: Файлы в списке слева станут **красными**. Это значит, что Git их увидел, но они еще не сохранены в историю (не закоммичены).

---

## 2. Первый локальный коммит (Save)
Прежде чем отправлять код в облако, его нужно сохранить у себя на компьютере.

1. Нажми **Ctrl + K** (Windows) или **Cmd + K** (Mac).
2. В открывшемся окне слева отметь галочкой пункт **Unstaged** (или просто выдели все файлы).
3. Напиши осмысленное сообщение, например: `Initial commit: base UI with ControlRow`.
4. Нажми кнопку **Commit**.
5. **Результат**: Файлы стали обычного цвета. Теперь у тебя есть "точка восстановления".

---

## 3. Выгрузка на GitHub в новый репозиторий
Самый быстрый способ создать репозиторий прямо из IDE:

1. Перейди в меню: **Git** -> **GitHub** -> **Share Project on GitHub**.
2. В появившемся окне заполни поля:
   * **Repository Name**: Имя проекта (например, `FitnessApp_KMP`).
   * **Private**: Поставь галочку, если не хочешь показывать код всему миру.
   * **Description**: Описание проекта (по желанию).
3. Нажми **Share**.
4. **Результат**: Android Studio сама создаст пустой репо на твоем аккаунте и сделает первый `Push`.

---

## 4. Параллельная работа: Как не запутаться?

### Как переходить между проектами?
Git привязан к **папке проекта**, а не к программе Android Studio. 
* Просто открывай два разных окна Android Studio (`File` -> `Open Recent`).
* Когда ты работаешь в Окне №1, все команды Git (Commit/Push) относятся **только** к Проекту №1.
* Когда ты переходишь в Окно №2, студия автоматически переключает контекст на Проект №2.

> **Важно:** Тебе не нужно ничего нажимать для "переключения" гита. Просто работай в нужном окне.

### Как проверить, куда уйдет код?
Посмотри в **правый нижний угол** экрана Android Studio. Там написано:
1. Название текущей ветки (обычно `main`).
2. Если кликнуть по нему, увидишь раздел **Remote**, где будет ссылка на твой GitHub репозиторий именно для этого проекта.

---

## 5. Ежедневный рабочий цикл (Workflow)

Каждый раз, когда ты написал что-то крутое (например, новую `ControlRow`):

1. **Commit (Локально)**: `Ctrl + K`. Пишешь что сделал -> Кнопка `Commit`.
2. **Push (В облако)**: `Ctrl + Shift + K`. Проверяешь список коммитов -> Кнопка `Push`.

---

## 6. Полезные горячие клавиши
| Действие | Windows/Linux | macOS |
| :--- | :--- | :--- |
| **Commit** (Сохранить) | `Ctrl + K` | `Cmd + K` |
| **Push** (Отправить на GitHub) | `Ctrl + Shift + K` | `Cmd + Shift + K` |
| **Update** (Скачать чужое/новое) | `Ctrl + T` | `Cmd + T` |
| **Показать вкладку Git** | `Alt + 9` | `Cmd + 9` |

---

### Что если я хочу "откатиться"?
Если ты что-то сломал, открой вкладку **Git** (внизу экрана), перейди в раздел **Log**, нажми правой кнопкой на предыдущий (рабочий) коммит и выбери `Reset Current Branch to Here` -> `Hard`. (Осторожно: это удалит незакоммиченные изменения!).
